# OS Quest

Offline gamified Operating System learning app for course 530205.

Open **Learn → Complete syllabus** to study the 10 sections of course 530205 in syllabus order. Each of the 70 topic entries includes a plain-English definition, an explanation, an example, an expandable exam definition and a recall question with a model answer. Recall progress is saved locally. Related lessons link to the glossary and exam practice.
